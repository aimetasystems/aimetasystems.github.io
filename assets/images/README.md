# Image assets

This draft uses only locally created SVG placeholders in `placeholders/`; it does not embed or hotlink external images.

Before launch, replace placeholders with laboratory-provided images or images whose reuse permission is confirmed. Suggested future locations:

- `hero-research-image.*` — Home hero visual
- `about-aim-lab.*` — Home research workflow or lab image
- `research-*. *` — research-area visuals
- `publications/<identifier>.*` — publication images supplied or approved by AIM Lab
- `members/<name>.*` — member portraits with consent

Use descriptive alt text in HTML/JSON when replacing images.
